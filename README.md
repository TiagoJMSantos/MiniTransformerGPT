# MiniTransformerGPT

A bare-metal Transformer inference engine implemented from scratch in RISC-V Assembly, alongside a custom 16-bit processor designed in Logisim.

**Grade:** 20.0 / 20.0

## Highlights

* Transformer self-attention implemented in RISC-V Assembly
* Matrix and vector operations
* Argmax token selection
* Custom 16-bit processor with dedicated vector units
* Assembly regression tests for core operations

## Technologies

* RISC-V Assembly
* Logisim

## Academic Context

University project focused on computer architecture, low-level programming, and hardware/software co-design.
